DECK//OS
CYBERDECK FIRMWARE FOR THE M5STACK TAB5

INSTALL

This browser can't talk to USB devices. Use Chrome or Edge on a desktop computer. Open this page over HTTPS to install.
Chrome or Edge on a desktop computer. Takes about a minute.

STEPS

  1. Connect the Tab5 to this computer with a USB-C data cable.
  2. Click INSTALL and pick the Tab5's port (it shows up as a USB JTAG/serial device).
  3. Confirm, and wait for the progress to finish.
  4. The Tab5 restarts into DECK//OS.

If no port appears, hold the Tab5's boot button while plugging it in, then try again.

GOOD TO KNOW

  • Installing here resets settings (Wi-Fi, theme, timezone). Notes and files on the SD card are not touched.
  • After this, updates arrive over Wi-Fi: SYSTEM > UPDATE.
  • Works on every Tab5 screen revision.
  • Pair it with the Tab5 Keyboard for the full deck.
